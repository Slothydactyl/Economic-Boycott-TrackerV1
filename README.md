## ⚠️ Legal Notice

This repository contains an interactive visualization of **publicly available information**, including:
- Court filings and legal documents (US v. Epstein, US v. Maxwell)
- SEC filings and financial disclosures
- Published investigative journalism (Miami Herald, NYT, etc.)
- Flight logs and address books released under FOIA

**Not all entities listed have been convicted of crimes.** This tool is designed for **economic research and consumer decision-making**. Verify all claims independently via primary sources.

## 🚀 Quick Start

No installation. No tracking. No server required.

### Option 1: Live (Online)
Open in browser: [https://github.com/Slothydactyl/Economic-Boycott-TrackerV1](https://slothydactyl.github.io/Economic-Boycott-TrackerV1/)

### Option 2: Offline (Recommended)
1. Download `BoycottTrackerV1.html` (or clone this repo)
2. Double-click to open in Firefox/Chrome
3. Works entirely offline—no internet connection required after download

**Privacy:** When run locally, this file makes zero network requests. Your research stays on your machine.
